# Detection Of Microplastics

## Introduction
This project aims to detect microplastics in water using sensor technology.

## Objective
- Detect microplastics in water.
- Improve water quality monitoring.
- Protect the environment.

## Technologies Used
- Python
- OpenCV
- HTML
- CSS
- JavaScript

## Project Modules
- Image Collection
- Image Processing
- Detection
- Result Display

## Future Scope
This project can be improved using Artificial Intelligence for better accuracy.
